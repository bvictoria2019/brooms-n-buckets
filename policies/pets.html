House rules

Pets and home access

Pets are welcome. We need a clear way in, and a home we can actually clean.

Pets

  • Friendly pets are welcome.
  • Please secure any pet that is anxious, overly excited, or uneasy with new people. A kennel or a separate room is fine.
  • Clean up pet waste before we arrive.
  • Heavy pet hair can add time and cost. Ask about that when you book.
  • We are not responsible if a pet gets out.
  • Tell us before the visit if a pet has a history of aggression, so we can plan a safe visit.
  • Puppies and homes with several pets: say so when you book.

Getting in

Please provide a working code, key, or entry instructions before the appointment. Include alarm codes, gate codes, and which door to use.

If we cannot get in because the code is wrong, a door is locked, or no one answers, the visit is a same-day cancellation. The full service amount is due. See booking and cancellation.

Utilities

Electricity, water, and heat or air conditioning need to be on and working. If they are off, we may not be able to finish the clean.
